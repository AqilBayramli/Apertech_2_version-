# Apertech website (React + Vite)

React version of `Apertech_2_ version` (Next.js). Same components, data, translations and styles;
routing is done with React Router instead of the Next.js app router.

```bash
npm install
npm run dev       # http://localhost:3000
npm run build     # typecheck + sitemap + production build into dist/
npm run preview   # serve dist/
```

- URLs: English has no prefix (`/`, `/solutions/genesis`), other languages live under `/az` and `/ru`.
  `/en/...` and the old static-site links (`/index.html`, `/solution-detail.html?solution=...`) redirect.
- Page titles, descriptions, canonical/hreflang links and JSON-LD are set by `src/lib/useSeo.ts`.
- `public/sitemap.xml` is generated by `scripts/generate-sitemap.mjs` (runs on every build).
- The host must serve `index.html` for every route (`vercel.json` does this on Vercel).
- Optional env vars: `VITE_SITE_URL`, `VITE_EMAILJS_PUBLIC_KEY`, `VITE_EMAILJS_SERVICE_ID`, `VITE_EMAILJS_TEMPLATE_ID`.
